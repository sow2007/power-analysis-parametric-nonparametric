# robust-power-analysis-of-parametric-anova-and-nonparametric-kw

---
USRESP SUBMISSION 2026
---

This is a power analysis simulator that compares the powers of both analysis of variance (ANOVA) and the Kruskal-Wallis _H_-test.

A guide on how to use can be found in the .R file as well. Please open using 'usresp project code.Rproj' so that all files stay organized. You can configure these settings in config.yml! Instructions are repeated in usresp project code.R file in comments as well.
